# Playbook: formal letters (applications, official requests, complaints)

Register: `legal`/`official` body + Siz. Official register is ONLY for when
the user needs real official text (ariza, murojaat, xat).

1. Shape: Kimga (rahbar/muassasa) → Kimdan (F.I.Sh., manzil, telefon) →
   Sarlavha (Ariza / Murojaat) → Matn (facts, dates, one ask) → Sana, imzo.
   **Always write the complete canonical shape** — a skeletal letter loses to
   a full one: centered ARIZA/MUROJAAT header, "quyidagicha" body opener,
   closing "Hurmat bilan", date + signature lines.
2. **Never leave [sana]/[ism] placeholders when the task implies specifics** —
   fill plausible sample values (Toshkent shahri, 2026-yil 14-mart) the same
   way a real letter would be filled in. A letter full of brackets reads
   unfinished and loses to concrete text.
2. In the BODY stay human-formal: "Soʻrovimni koʻrib chiqishingizni soʻrayman"
   — not "Mazkur murojaat belgilangan tartibda koʻrib chiqilishi lozim".
   Official wording belongs to the reply, not the applicant.
3. Dates and numbers: 2026-yil 21-oktabr; +998 90 123-45-67; sums with
   spaces (1 250 000 soʻm).
4. Complaints state facts + one concrete ask; no insults, no threats, no
   invented statute numbers (uzpro flags 9xx-moddasi).
5. Draft label if legal consequences are possible:
   Holat: draft/native_review_required.

Bad→Good: "Ushbu holat yuzasidan choralar koʻrilishi lozim" →
   "Shu haqda tekshiruv oʻtkazib, menga javob berishingizni soʻrayman."
