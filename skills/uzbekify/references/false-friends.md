v1's 6 rows.

## Uzbek-Russian pairs agents confuse

| Uzbek word | RU lookalike trap | Rule |
|---|---|---|
| yoʻq | нет existence vs "no" answer | Yoʻq works for both in UZ; don't write "net" |
| oxirgi / soʻnggi | последний | oxirgi = final, soʻnggi = latest — pick by sense |
| boʻsh | пустой/свободный | boʻsh = empty/free; "bush oʻrin" → boʻsh oʻrin |
| qattiq | твердый/сильно | qattiq = hard/severe; do not use for "very" |
| tez | быстрый | tez = fast (speed); "tez orada" = soon — fine |
| yengil | легкий | yengil = light-weight/easy; "yengil tilda" = plain language |

## Rule

If a plain Uzbek word exists for the sense, prefer it over the
internationalism that only looks smart. Keep the international word when it
IS the domain term (informatsion texnologiyalar → axborot texnologiyalari is
the modern standard; old texts still have informatsion).
