## Micro-copy completeness

UI text must be short AND informative. "Papkalar endi bor" is too bare for a
release note — say what the folders do for the user ("Papkalarga ajratib
saqlang"). Buttons keep precise objects ("Havola yaratish", not "Doʻst
taklif qilish" for a link flow). Masked cards use the bank convention:
"•••• 4455 bilan tugagan karta".

## Register note

User self-signup = Roʻyxatdan oʻtish; admin enrollment = Roʻyxatga olish.
Never mix the two on one surface (v1 rule, kept).
