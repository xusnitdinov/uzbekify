# Idioms and natural connectors

## 1. Idiom policy (unchanged from v1, kept verbatim in spirit)

1. Never invent idioms or maqollar.
2. Remap only when sure the Uzbek idiom really matches.
3. Otherwise paraphrase plainly.
4. Watch ambiguity: koʻz yummoq = overlook OR die; check context.

## 4. Natural connectors (what native prose actually uses)

| Function | Natural | Officialese/calque (avoid in default copy) |
|---|---|---|
| because | chunki / -gani uchun | sababli (ok formal) / "belgi sababli" chains |
| so / therefore | shuning uchun | shu sababli ham + stacking |
| but | lekin / ammo / biroq | ammo ammo… (formal only once) |
| however | bunday boʻlsa-da / shunga qaramay | shu bilan birga, ayni paytda (stack) |
| also | ham, shuningdek | bundan tashqari, qoʻshimcha (double) |
| for example | masalan | misol uchun (ok) + "jumladan" spam |
| in short | qisqasi | yakuniy xulosa qilib aytganda |
| that is | yaʼni | boshqa soʻzlar bilan aytganda (calque) |
| finally | oxiri / vanihoyat | oxirgi navbatda (RU sense drift) |
| first | avval / birinchidan | birinchi navbatda (3+ uses) |
| meanwhile | shu orada | oʻsha paytda (ok) / "shu bilan birga, ayni paytda" |
| instead | uning oʻrniga | buning ustiga (means 'on top of that') |
| on the one hand | bir tomondan … ikkinchi tomondan | bir tomondan … boshqa tomondan (calque pair) |
| as a result | natijada | buning natijasida sifatida (double stack) |
| according to | -ga koʻra / maʼlumotlariga qaraganda | boʻyicha (3+ per paragraph) |
| regarding | toʻgʻrisida / haqida | boʻyicha spam |

## 5. Particles and spoken glue (chat registers only)

ku/axir (insistence: Axir bu mumkin emas-ku), -chi (Sen-chi?), -mi
(question), -da (men-da), -gina (ozgina), mayli, xoʻp, endi, baribir,
shunchaki, mana, boʻlmasa, qani, zoʻr.

Rules: product UI — none; assistant — ≤1 per message; youth — natural
density. Never stack particles to "sound human" (-ku-da-yu in one sentence).

## 6. Discourse-openers that mark AI text (kill on sight)

- Haqiqatan ham, … (as an opener)
- Xoʻsh, keling boshlaymiz! (template-y)
- Albatta! Bu yerda … (chat opener)
- Tabriklar! Siz … (unearned)
- Ajoyib savol! (sycophancy)
- Xulosa qilib aytganda, … (in a 3-sentence answer)
