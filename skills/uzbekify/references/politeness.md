# Politeness and address lanes

## Address lanes

| Context | Lane |
|---|---|
| Product UI, quiz, gov, strangers, elders | Siz + -siz/-asiz/-ingiz (Keling, Yozing, qilasiz) |
| Peer / friend / child / Telegram youth | sen + -san/-asan + bare imperative (Kel) — only on request |
| Extra respect | Aka/Opa + Siz (keep formal endings) |
| User → company | plural -inglar (qoʻyinglar) is polite; never "fix" it down |

## Hard rules

1. One lane per surface: never Siz + -san in one screen/reply.
2. Product/quiz default is Siz — no "-san because it sounds friendlier".
3. `SIz` casing typo is an error; one casing style per surface.
4. Keep sen inside quotes (user-voice reviews); do not copy -asan into FAQ —
   rewrite as Siz or impersonal.

## Soft formulas (assistant/support)

- Iltimos …
- Zahmatingiz boʻlmasa …
- Marhamat …
- mumkin boʻlsa …
- Xohlasangiz …
- Request shape: sentence-final -sangiz ("batafsil yozib yuborsangiz.")

## Disagreement ladder

| To whom | Say | Never |
|---|---|---|
| Elder/professor | Fikringizga qoʻshilmayman | Siz notoʻgʻrisiz |
| Peer expert | Menimcha, bu yerda boshqacha variant ham bor | bu ahmoqona |
| Written/wiki | Buni ham sozlab qoʻysangiz, yaxshi boʻlardi | qatʼiyan qoʻshilmayman (flame) |
| Support | Bunda chalkishlik boʻlgan koʻrinadi | sizlar bilmasiz |

## Apology and thanks

| Situation | Say | Avoid |
|---|---|---|
| Small mishap | Uzr, noqulay boʻldi | Keltirilgan noqulayliklar uchun uzr soʻraymiz (stiff) |
| Real incident | Noqulaylik uchun uzr soʻraymiz, sababi … | template apology with no cause |
| Thanks (support) | Rahmat | Murojaatingiz uchun rahmat (ok once, not every line) |
| Review thanks | Izohingiz uchun tashakkur | Qayta aloqa uchun rahmat (RU calque) |

## Greetings

- Assalomu alaykum! — support openers, any time of day
- Salom! — peers only
- Never: Hurmatli foydalanuvchi (brochure), Dear user calques

## Addressing teams

Users address companies in plural (qoʻshinglar, beringlar) — do not flatten.
Companies address users in Siz singular. Yodingizda: "Sizlar" for a user
audience is fine in marketing ("Sizlarga ham") but pick one per campaign.
