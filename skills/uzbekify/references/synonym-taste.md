# Native synonym taste (matrices)

Same English source → different Uzbek by situation. v1's matrices covered
product/quiz; this adds emotion, politeness, certainty, news, academic and
legal rows.

## 1. Failed-outcome verbs (the chiqmadi trap)

| Context | Prefer | Avoid as default |
|---|---|---|
| Group project / team dynamics | oʻxshamadi | chiqmadi, portladi |
| Plan execution | amalga oshmadi | chiqmadi |
| App bug / feature output | ishlamadi, chiqmadi (literal output OK) | oʻxshamadi |
| Device / startup | ochilmadi, yoqilmadi | chiqmadi |
| Relationship / cooperation | yurishmadi, kelisha olmadik | chiqmadi |
| Exam performance | yaxshi oʻtmadi | chiqmadi |
| Payment flow | amalga oshmadi | chiqmadi |
| Delivery | kechikdi, yetib kelmadi | chiqmadi |
| Event | boʻlib oʻtmadi / bekor qilindi | chiqmadi |

## 12. Banking/finance collocations (the account-verb traps)

| Situation | Wrong (calque/garble) | Correct |
|---|---|---|
| Account closes monthly | Kitoblaringizni yopib beramiz | Hisob-kitob har oyning 5-sanasigacha yopiladi |
| Money arrives | pul hisobga tushirildi | pul hisobga tushdi |
| Top up | balansga pul qoʻyish | balansni toʻldirish |
| Charge twice | ikki marta pul olishdi | ikki marta yechib oldi (user) / ikki marta yechildi |
| Refund path | pul qaytarilishini amalga oshiramiz | pul qaytib tushadi / qaytarib beramiz |
| Fixed monthly fee | qatʼiy oylik toʻlov qilinadi | oyiga bir xil toʻlovsiz / oylik bir xil |
| Statement | kitob / hisob kitoblaringiz | hisob-varaq / hisobot (by product) |

"Kitob" = book. Money accounts are hisob/hisob-kitob; statements are
hisob-varaq. Getting this word wrong is an instant credibility loss.
