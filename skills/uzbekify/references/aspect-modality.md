# Aspect and modality

Uzbek marks aspect with converb + auxiliary compounds, not with tenses the
English way. AI Uzbek underuses the compounds (sounds textbook) or stamps
-gan everywhere (sounds wrong). Expanded from v1's 28-line version.

## 1. Core aspect compounds

| Form | Feel | Example |
|---|---|---|
| -ib qoʻymoq | done-for-me / polite completed | eshikni yopib qoʻying |
| -ib yubormoq | sudden, blurted, away | aytib yubordi |
| -ib qolmoq | ended up, remained | tushunib qoldim |
| -ib ketmoq | went and did (change of state) | kulib yubordi; ketib qoldi |
| -ib turmoq / -ib oʻtirmoq | ongoing right now | kutib turibdi |
| -a turibdi / -yapti | progressive | yozyapti, ishlayapti |
| -ib boʻlmoq | finished (completive) | yozib boʻldim |
| -ib olmoq | for one's benefit | olib qoʻydi, yozib oldim |
| -ib bermoq | do for someone | ochib berdi |
| -ib koʻrmoq | try and see | sinab koʻring |
| -a boshlamoq | inceptive | yozishni boshladi |
| -avermoq | keeps doing | yozaveradi |

## 2. English tense → Uzbek aspect

| English feel | Prefer | Not |
|---|---|---|
| for ten years (ongoing) | oʻn yildan beri + present | oʻn yil boʻldi + past |
| is reading | oʻqiyapti | oʻqimoqda |
| has been working since | -dan beri ishlab keladi | -gan edi |
| always complaining | doim shikoyat qilib yuradi | har doim shikoyat qiladi (ok but flat) |
| just finished | tugatib boʻldim | tugatdim (fine, weaker) |
| used to | -ar edi | -gan edi |
| will have done | -ib boʻladi / boʻlgan boʻladi | boʻladi edi |

## 3. Modality

| Sense | Prefer | Example |
|---|---|---|
| must / have to | kerak / lozim / shart | Borishim kerak |
| need (object) | kerak | Suv kerak |
| should have (counterfactual) | kerak edi | Aytganingiz kerak edi |
| can (ability) | -a olmoq | Suzib olaman |
| can (permission) | mumkin / boʻladi | Kirish mumkinmi? |
| may (possibility) | -ishi mumkin | Kechikishi mumkin |
| would (polite) | -sangiz / -siz mumkin | Yozsangiz, boʻladi |
| want | -moqchi / istamoq | Bormoqchiman |
| about to | -moqchi / zoʻri bosmoq | Ketmoqchiman |
| let's | -aylik / Keling, -ay | Keling, boshlaylik |
| don't | -ma (+ softener) | Bilmadim, oʻchirmang |

## 4. Evidentiality (diʼtan ovozi)

| Form | Use | Example |
|---|---|---|
| -di | direct knowledge | Keldim |
| -gan / -ibdi | witnessed/reported | kelibdi |
| -gan ekan / ekan | discovered | kelgan ekan |
| -gan emish | hearsay | kelgan emish |

Do not stamp -gan for English present perfect: "I have finished" →
Tugatdim (natural) or tugatib boʻldim (completive), not tugatganga? and not
tugatgan edim (that is "I had finished").

## 5. Articles (English a/the)

Uzbek has no articles:

- Default: omit. Bir only when indefiniteness matters: Bir kun (once upon a
  time), biror kitob (some book).
- Specific "the" → -ni: Kitobni oʻqidim (I read the book) vs Kitob oʻqidim
  (I read a book / books in general).
- Never sprinkle bir on every noun (AI habit): ✗ bir talaba bir kitobni bir
  kun oʻqidi.

## 6. Negation

- Standard: verb + -ma/-me: bilmadim, kelmaydi.
- Yoʻq for nouns/existence: Vaqt yoʻq. Emas for predicate negation: Bu kitob
  emas.
- Double negation is NOT intensification (unlike RU): ✗ hech kim kelmadi
  yoʻq → ✅ Hech kim kelmadi.
- "Not only… but also": nafaqat … balki … ham — one nafaqat, one balki.
