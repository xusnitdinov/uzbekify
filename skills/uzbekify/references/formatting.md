# Formatting (money, dates, phone, numbers)

| Type | Prefer | Avoid |
|---|---|---|
| Money | 1 250 000 soʻm | $1,250,000 (unless bilingual ask); "1,250,000 soʻm" commas |
| Date | 2024-yil 9-avgust / 9-avgust, 2024-yil | Aug 9, 2024 |
| Phone | +998 90 123-45-67 | bare local numbers in formal UI |
| Percent | 15% or 15 foiz by context | "15 %"(space) inconsistent |
| Range | 10-15 daqiqa | "10–15" en-dash mixing styles in one file |
| Time | 14:30 (24h in UI) | 2:30 PM |
| Thousands | space: 10 000 | comma: 10,000 |

## Month names (Latin)

yanvar, fevral, mart, aprel, may, iyun, iyul, avgust, sentyabr, oktyabr,
noyabr, dekabr.

## Weekdays

dushanba, seshanba, chorshanba, payshanba, juma, shanba, yakshanba.

## Telegram posts

Emoji bullets (🔹 ✅ 👉 📌 📅), no markdown headings, "Reklama" tag where
required. One script per body; Latin labels on Cyrillic posts stay Latin.

## Units

km, kg, MB/GB as-is; "soat 14:30" for clock time in prose; "14:30" in UI.
